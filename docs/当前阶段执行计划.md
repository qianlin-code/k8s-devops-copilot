## 阶段目标与用户流程

目标是把已经可运行的 K8s / DevOps 智能运维 Copilot 收敛为可在 GitHub 展示、可由招聘者理解、可从干净克隆复现且不夸大能力的 v1.0 求职项目。

- 阶段整体涉及后端、前端、模型、数据、Docker 和发布多个 owner，实施任务默认按行为决定 T1/T2/T3，不能用阶段的 T2 替代每个改动自己的测试门禁分类。

## 验证方法

1. 基线：在选定 commit 的干净目录按锁文件安装，执行后端完整 pytest、前端 typecheck/build 和当前关键 E2E，记录测试发现数量与退出码。
2. 评测：使用固定数据版本、模型和参数运行检索/路由/生成/引用评测，保存逐条结果与失败案例；达到门槛与否只更新评测和验收 owner。
3. 部署：使用独立 Compose project、端口和卷从干净克隆执行配置、构建、初始化、API/浏览器演示、停止与重启持久化检查。
4. 发布：核对远端 CI、公开数据许可、敏感信息、仓库体积、Markdown 链接、截图/录屏和 Release 内容。
5. 收口：执行项目验收标准的全部必过项；Skill 阶段护栏结构通过不代表运行或发布验收通过。
