# 运维 Copilot 数据来源与许可

本文档是知识语料来源、许可、哈希和处理过程的唯一登记位置。指标所使用的数据集版本必须引用本文件或对应 commit。

## 1. 数据边界

- `backend/data/docs_k8s/`：当前业务知识库语料，基于 Kubernetes 官方文档主题整理。
- `backend/data/eval_set.json`：K8s 知识与工具路由评测标注，不是训练集。
- `backend/app/storage/seed.py`：Pod、Deployment、告警和工单演示状态，属于合成数据。
- `backend/data/docs/` 与 `docs_education/`：历史客服/跨行业验证语料，不属于对外 K8s 主数据集。

README 和简历必须明确：知识资料来自真实公开文档，集群状态和写操作是演示 mock，不得宣称连接生产集群。

## 2. 许可与整理方式

Kubernetes 网站文档仓库声明文档内容使用 CC BY 4.0，代码示例使用 Apache 2.0。本项目语料不是上游页面的镜像，而是基于下方页面整理的中文故障排查摘要：仅保留现象、根因和处理步骤，删除网站导航与无关段落；不在业务代码或语料中为固定评测题添加关键词。每份本地文件均保留上游链接、获取日期和本地 SHA-256，以满足 CC BY 4.0 的署名与可追溯要求。

- 上游仓库：<https://github.com/kubernetes/website>
- 许可说明：<https://github.com/kubernetes/website/blob/main/LICENSE>
- 文档站点：<https://kubernetes.io/docs/>

本项目代码许可证为根目录 `LICENSE` 中的 MIT；它只覆盖本项目代码，不覆盖下列 Kubernetes 整理语料。

## 4. 处理与版本规则

1. 保存原始 URL、上游标题、许可、获取日期和原始内容哈希。
2. 只摘取故障现象、根因和处理步骤等必要段落，保留上游署名。
3. 统一 Markdown 标题结构，代码块保持完整，不为命中评测问题添加隐藏关键词。
4. 入库前运行切片检查，排除导航、空白和重复 chunk。
5. 语料变更后更新本清单、数据集版本并重跑检索评测。

## 5. 评测集治理

- 评测集与 Prompt 示例、前端推荐问题分离。
- 知识问题、工具问题和安全/不足分支分别标注，指标分开统计。
- 每条记录保留 case ID、期望结果、期望工具和人工依据。
- 不允许根据 case ID 或固定问题文本在业务代码中硬编码结果。
- 正式报告保存数据集 SHA-256、样本数和 commit SHA。

## 6. GitHub 发布规则

- 只提交许可允许再分发且已完成来源登记的文本。
- 不提交 `.env`、数据库、Qdrant 运行目录、日志、真实用户输入或模型缓存。
- 合成运行状态必须标为 mock；不得伪装成企业真实集群数据。
- 若无法确认某份资料的许可，GitHub 只保留来源 URL、下载/预处理说明和哈希，不提交原文。
