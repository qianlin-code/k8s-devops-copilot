# 登录与认证故障排查手册

## 403 Forbidden 权限不足

### 现象
用户输入正确的账号密码，登录接口返回 403 Forbidden，前端提示"无访问权限"。

### 根因
账号的 permission_level 字段为 restricted，未被授予目标应用的访问权限。
这与密码错误（401）是完全不同的两类问题。

### 处理步骤
1. 用账号查询工具确认 permission_level 当前取值
2. 若为 restricted，联系空间管理员在后台提权到 standard
3. 提权后必须刷新权限缓存，否则变更最长 15 分钟后才生效
4. 让用户重新登录验证

## 401 Unauthorized 凭证失效

### 现象
用户此前能正常使用，突然所有请求返回 401，需要重新登录。

### 根因
访问令牌（access token）已过期，或用户在其他设备触发了单点登出。
默认令牌有效期为 8 小时。

### 处理步骤
1. 让用户退出后重新登录，获取新令牌
2. 若反复出现，检查客户端是否未正确处理令牌刷新逻辑

## 账号被风控锁定

### 现象
提示"账号已锁定，请联系管理员"，状态查询显示 status 为 locked。

### 根因
连续 5 次密码错误会触发风控自动锁定，锁定时长 30 分钟。

### 处理步骤
1. 查询账号状态确认 locked_reason
2. 等待 30 分钟自动解锁，或由管理员手动解锁
3. 建议用户使用密码管理器避免重复错误

## 欠费导致服务暂停

### 现象
登录后提示"服务已暂停"，功能全部不可用，状态查询显示 status 为 suspended。

### 根因
订阅账期逾期未付款，系统自动暂停服务。

### 处理步骤
1. 用订单查询工具确认是否存在 overdue 状态的订单
2. 提醒客户完成付款
3. 付款到账后服务在 1 小时内自动恢复，不需要人工干预
4. 注意：suspended 状态的账号无法执行权限缓存刷新操作
