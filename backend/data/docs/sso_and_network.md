# SSO 单点登录与网络接入

## SSO 跳转后白屏

### 现象
点击"企业微信登录"跳转回来后页面白屏，控制台报 CORS 错误。

### 根因
IdP 回调地址与应用配置的 redirect_uri 不一致，或回调域名未加入 CORS 白名单。

### 处理步骤
1. 核对 IdP 后台配置的回调地址与应用 redirect_uri 是否逐字符一致
2. 确认回调域名已加入网关 CORS 白名单
3. 清理浏览器缓存后重试

## SAML 断言校验失败

### 现象
SSO 登录报"断言签名无效"，日志出现 SignatureVerificationError。

### 根因
IdP 侧轮换了签名证书，但应用侧的元数据未同步更新。

### 处理步骤
1. 从 IdP 重新下载最新的 metadata XML
2. 在管理后台更新 SAML 元数据
3. 无需重启服务，配置在 5 分钟内热加载生效

## 内网访问超时

### 现象
在公司内网访问返回 504 Gateway Timeout，用手机流量访问正常。

### 根因
企业防火墙拦截了应用所需的出站端口，或代理未放行相关域名。

### 处理步骤
1. 确认防火墙已放行 443 端口到应用域名
2. 若使用正向代理，将应用域名加入代理白名单
3. 用 curl -v 抓取握手过程定位具体阻断环节

## VPN 环境下频繁掉线

### 现象
连接 VPN 后每隔几分钟就掉线需要重新登录。

### 根因
VPN 出口 IP 频繁变化，触发了应用的会话 IP 绑定校验。

### 处理步骤
1. 在安全策略中为该 VPN 出口网段关闭 IP 绑定校验
2. 或让用户改用固定出口的 VPN 节点
