# 成绩与成绩单常见问题

## 查不到本学期成绩

### 现象
登录教务系统后，本学期已结课的课程成绩栏显示为空。

### 根因
成绩录入有统一的开放窗口，任课教师需在考试结束后两周内完成录入并提交审核，
审核通过前学生端不可见。

### 处理步骤
1. 确认是否已过教务处公布的成绩录入截止日期
2. 若已过截止日期仍查不到，联系任课教师确认是否已提交
3. 若教师已提交超过 3 个工作日仍未显示，联系教务处排查审核环节

## 成绩有异议，怎么申请复核

### 现象
学生认为某门课程的最终成绩与预期不符，希望申请复核。

### 根因
成绩复核需要走教务处规定的正式流程，不能直接找教师口头修改，避免个案争议影响公平性。

### 处理步骤
1. 在教务系统提交"成绩复核申请"，说明具体课程与复核理由
2. 复核申请会转交课程所在院系的教学秘书登记
3. 教师在收到复核通知后 5 个工作日内需给出书面回复
4. 复核结果（维持或修改）会同步更新到教务系统并通知学生

## 打印的成绩单和系统里的不一致

### 现象
自助打印的成绩单上缺少某门课程，但教务系统在线查询能看到。

### 根因
成绩单打印使用的是每晚定时生成的静态快照，当天新增或修改的成绩需要等到次日快照才会同步。

### 处理步骤
1. 确认该门课程成绩是否为当天新录入或修改
2. 若是，等待次日再重新打印
3. 若已超过一个工作日仍不一致，属于系统同步异常，联系教务处技术支持登记工单

## 双学位/辅修的成绩单怎么获取

### 现象
学生同时修读主修与辅修专业，不知道如何获取包含两个专业课程的完整成绩单。

### 根因
系统默认按主修专业生成成绩单，辅修课程需要单独勾选才会合并显示。

### 处理步骤
1. 在成绩单打印页面勾选"包含辅修课程"选项
2. 若辅修专业未在系统里正确关联，需先联系辅修所在院系教务秘书确认学籍关联
3. 关联确认无误后，成绩单会自动包含辅修课程与对应学分
